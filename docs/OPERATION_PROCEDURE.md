## 0. 원칙

- 아이라는 N.I.N.A.의 기능을 쓰되 **초·중급자가 헤매지 않는 촬영 프로그램**. N.I.N.A.·PHD2·SharpCap·Wanderer Empire를 쓰는 것이 전제다.
- **AI는 판정 고리 밖**: 등급·재시도·멈춤은 규칙(코드)이 정하고, AI는 설명 문구만(1초마다 바뀌는 값에 AI를 쓰지 않음).
- **실패는 아이라가 먼저 처리**: 정해진 순서로 다시 시도하거나 대안으로 바꾸고, 끝내 안 될 때만 무엇이 / 왜 / 이제 뭘 할지를 보여 준다.
- **실패해도 밤이 막히지 않게**: 장비 문제로 실패하면 "다시 시도"와 함께 그 작업을 넘기는 선택을 둔다(3장).
- **의미 없는 확인은 묻지 않는다**: 사용자가 할 일이 없으면 건너뛴다(예: 프로필을 고를 때 설치 상태가 모두 정상이면 설치 확인 화면 없이 다음으로, 빠진 게 있으면 빠진 첫 항목부터).
- **인터넷**: 시작·계획 단계는 온라인 필수(휴대폰 핫스팟 등), 촬영이 시작된 뒤에는 끊겨도 촬영은 계속 — AI 대화·예보 갱신만 멈추고 상태 줄에 알린다.
- **N.I.N.A. 설정은 바꾸지 않는다**(예외: 관측지·망원경은 아이라 값을 써 넣음, 허브 출력 켜기).

### 장비 안전 (모든 단계 공통)
- 적도의는 **Go Home(홈으로 이동)만** 쓰고 **Set Home(지금 위치를 홈으로 덮어쓰기)은 절대 쓰지 않는다**.
- 움직이는 동작을 멈출 때는 **멈춘 것을 확인**한다. 확인하지 못하면 "중단 완료"가 아니라 **"장비 상태 다시 확인"** / **"멈춘 것을 확인했어요"**(사용자가 장비를 직접 보고 풀기, 앞 실행이 끝난 뒤에만) — 그때까지 그 장비를 움직이는 다른 작업을 하지 않는다. 적도의는 N.I.N.A.가 **연결 안 됨**이라고 분명히 답하면: 이번 실행에서 연결된 적이 없으면 아이라가 움직였을 리 없으니 멈춘 것으로, 연결돼 있다가 끊겼으면 움직이던 중일 수 있어 모르는 것으로 본다.
- 적도의를 움직이는 일은 한 번에 하나. 크게 돌리기 직전에는 케이블 안내(극 찾기 · 캘리브레이션 위치 이동 · 대상 이동 · 자오선 반전).
- **X-T5는 노출을 중단하지 않는다**: 일반 노출은 소프트웨어로 중단되지 않는다(N.I.N.A. 후지 플러그인이 거절하고, N.I.N.A.는 "중단됨"이라 답한 뒤 시간 초과 오류). 멈추기·종료·가이드 별 잃음 모두 지금 노출이 끝나기를 기다린다. 노출이 정지 확인 한도(15초)보다 길면 "장비 상태 다시 확인"이 뜨고 노출이 끝난 뒤 누르면 풀린다.
- 아이라가 꺼질 때는 적도의 추적을 끄고(상태를 읽지 못하면 끈 것으로 치지 않음), 포커서를 0으로 보낸다(10장).
- 포커서 끝은 제조사 보호에 맡긴다: Oasis는 멈춤 감지를 켜 두고, 아이라는 포커서가 알려 주는 범위 안에서만 움직인다.

## 1. 단계

**점검 → 연결 → 장비 준비 → 대상 → 촬영 → 마무리**
- 점검 = 출발 전 점검(프로필 바로 다음 — 장비를 세운 차례와 맞고, 프로필 화면에서 미리 켜기 시작한 N.I.N.A. 등이 그동안 켜진다) / 연결 = 설치 확인 · 엔진 켜기 · 장비 연결.
- **장비 준비** = 한 번 해 두고 그날 유지(극축 정렬 · 캘리브레이션 · 초점). **대상** = 대상마다 반복(계획 ↔ 이동 · 센터링 · 초점 확인 · 가이드 · 시험 사진).
- 진행은 서버가 하고 화면은 상태만 그린다 → 화면을 다시 열어도 이어서.

## 2. 시작 · 연결

### 아이라 시작
- **프로필 화면이 처음 뜰 때 N.I.N.A.·PHD2·Wanderer Empire를 미리 켠다**(꺼져 있을 때만, 설정에서 자동 켜기가 켜져 있을 때). 프로필을 고르는 동안 준비돼 엔진 켜기는 확인만 한다. 종료 창에 닫을 프로그램으로 나온다.

### 엔진 켜기
- N.I.N.A.가 꺼져 있으면 켜고(이미 미리 켰으면 준비를 기다림) → 연결 통로(Advanced API) 응답 → 인터넷 확인. N.I.N.A.가 여러 개 켜져 있으면 닫지 않고 알린다.
- 연결되면 N.I.N.A.를 지켜본다(9장 "N.I.N.A.가 꺼지거나 멈췄을 때").

### 장비 연결
- **장비 등급**. N.I.N.A. 프로필에 "없음"인 장비는 다루지 않는다(필수만 예외)

  | 등급 | 장비 | 프로필에 없음 | 연결 실패 |
  |---|---|---|---|
  | 필수 | 카메라, 적도의, 망원경 | 실패: "N.I.N.A.에 등록된 ○○가 없습니다" | 멈춤, "다시 연결" |
  | 준필수 | 포커서, 가이더 | 미등록 | "다시 연결" + **"○○ 없이 진행"**(가이더 없음 → 노출 120초 이하 추천, 포커서 없음 → 손 초점 안내) |
  | 선택 | 전원 허브, 필터휠, 회전장치, 플랫패널 | 미등록 | 경고만 하고 계속 |
  | 다루지 않음 | 돔, 안전 모니터, 날씨 장치 | — | — |

- **전원 허브는 있으면 맨 먼저**. 실패하면 배선상 허브에서 전원을 받는 장비만 보류한다 — 그래도 PC에 보이면 전원이 있다는 증거라 연결한다(docs/implementation/POWER_WIRING.md). 다시 연결하면 처음부터. 연결되면 허브 USB 출력을 켜 둔다.
- 연결 전에 장비가 PC에 보이는지 한 번만 확인하고, 안 보이면 N.I.N.A.에 맡기지 않고 할 일을 알린다(허브 출력을 방금 켰으면 10초까지 기다림). 카메라 전원을 허브 출력에서 받게 정했으면 카메라가 PC에 없을 때 그 출력을 켜고 20초 기다린다.
- **가이더**: N.I.N.A.의 "가이더 연결됨"은 PHD2 프로그램에 붙었다는 뜻뿐 → PHD2에 직접 물어 PHD2 안의 카메라·적도의가 연결됐는지, 적도의가 시뮬레이터가 아니고 N.I.N.A.와 같은 장비인지(카메라 ST-4 보정은 예외) 확인. 같은 가이드 카메라가 다른 USB 자리에 꽂혀 PHD2가 못 찾으면 PHD2 설정의 카메라 자리를 지금 자리로 고쳐 다시 연결하고(같은 장치가 하나만 꽂혀 있을 때만), 안 되면 원인별 안내(카메라가 PC에 없음 / 같은 카메라가 여러 대). PHD2에 직접 닿지 못하면 막지 않는다.
- **망원경**은 연결하는 장비가 아니라 아이라 목록에서 고른다(4장). 연결 화면에서 바꾸면 그 자리에서 다시 확인.
- 모두 연결되면(준필수 "없이 진행"·선택 경고 포함) 4초 뒤 다음 단계. 그동안 "장비 변경"·관측지 "변경"을 누르면 멈춘다(3.5초까지). 관측지가 없으면 관측지 고르기로.
- **장비 변경**: 고른 장비는 N.I.N.A. 프로필에 등록하고, "변경 완료"면 **바뀐 장비만** 다시 연결(전원 허브가 바뀌면 처음부터). 카메라 전원(배터리 / 허브 출력)을 허브 출력으로 고르면 그 출력 전압을 어댑터에 맞췄는지 확인받는다(아이라는 전압을 읽거나 바꾸지 못함).

## 3. 관측지 · 망원경 · 프로필 데이터

### 관측지
- **기준은 아이라**: 관측지는 프로필마다 목록(최대 10개, 이름 + 위도·경도 + 고도 자동)으로 저장하고, N.I.N.A.는 아이라 값을 따른다. 지금 관측지 = N.I.N.A.에 설정된 좌표(0,0이면 없음).
- 관측지를 고르면 동기화: N.I.N.A.에 저장 → 적도의에 위치 보내기. 이미 지금 관측지면 동기화 없이.
- 좌표는 고치지 않는다(이름만). 지금 관측지는 지울 수 없다. 저장되지 않은 지금 관측지는 목록에 넣지 않는다 — 프로필을 바꿔 지금 관측지가 그 프로필에 없으면 "(저장 안 됨)"으로 보이고, 저장하지 않고 끄면 그 프로필에는 남지 않는다.

### 망원경
- 망원경(또는 렌즈)은 N.I.N.A.가 모른다 → **아이라의 망원경 목록이 기준**, 고른 망원경의 초점거리·F값·이름을 N.I.N.A.에 써 넣는다(화각·플레이트 솔빙).
- 목록은 **프로필과 관계없이 하나**, 최대 10개, 모두 직접 입력: 이름 · 초점거리 · 구경 또는 F값(나머지는 계산) · 리듀서·플래트너 배율(선택). 실제 값 = 배율을 곱한 값. 지금 망원경은 지울 수 없다.

### 프로필
- 프로필 = 별명·메모·사진 + 관측지 목록 + 전원 설정. 바꾸면 관측지는 그대로(지금 서 있는 장소).
- **전원 설정**: 아이라는 이 배선을 믿고 안내하고(예: "파워박스는 적도의에서 전원을 받습니다…"), 실제와 다른 증거를 보면 조용히 고친다(`docs/implementation/POWER_WIRING.md`).
- 삭제하면 관측지 목록과 전원 설정도 지워지고 되돌릴 수 없다.

## 4. 출발 전 점검

아이라가 스스로 알 수 없고 **자주 잊는 것만** 묻는다. 장비를 세우는 과정에서 빠질 수 없는 일(케이블·밸런스·삼각대 수평)은 묻지 않는다.
- 설치하는 차례대로 4개: **포커서 0점**("포커서 노브를 끝까지 넣어 0에 맞췄나요?") → **적도의 전원**("적도의 전원을 켰나요?") → **적도의 시작 위치**("적도의를 북쪽으로 향하게 세우고 홈 자세로 두었나요?" — 이 적도의는 전원을 켜도 움직이지 않으므로 전원 뒤) → **망원경 캡**("망원경 뚜껑을 모두 열었나요?").
- **포커서 0점은 매번 묻는다**: 사용자는 포커서를 늘 떼어 보관하고 노브가 돌면 드로튜브가 움직인다. 0이 바깥으로 어긋나면 안쪽은 갈 수 없고, 기억한 초점이 어긋나며, 넓게 찾기가 바깥 끝을 민다. 점검을 마치면 초점 작업이 0점을 잡는다(Oasis는 제조사 SDK로 자동, 다른 포커서는 드라이버 설정 창에서 직접). 이어서 하기는 점검을 건너뛰므로 잡지 않는다.
- 모두 확인하면 노트북을 눌러 다음(설치 확인)으로. 오늘 밤 진행을 이어서 하면 묻지 않는다.

## 5. 장비 준비 · 대상

### 공통
- **작업 끝은 사용자가 누른다**: 결과를 보여 주고, 끝 버튼이 다음 작업을 시작한다(이동 승인도 이 버튼). 작업 안의 세부 과정은 자동이어도 된다. 장비 준비 시작 = 극축 정렬 바로 시작.
- **작업 순서**: 장비 준비 = 극축 정렬 → 캘리브레이션 → 초점(끝 버튼 "대상 고르기"). 대상 = 계획 → 이동 → 센터링 → 초점 확인("이 대상으로 확정") → 가이드 → 시험 사진(끝 버튼 "촬영 시작"). 서버는 "직전 작업 끝"이 아니라 실제 조건(센터링엔 솔빙 가능한 초점, 가이드엔 유효한 보정값)으로 관리한다.
- 장비 준비는 대상과 무관해 계획 전에 해도 된다(박명 중 북극성이 보일 때). 결과는 "그날 밤"에 묶여 대상을 바꿔도 유지. 적도의를 건드렸으면 극축 정렬부터, 가이드 카메라를 뺐다 꽂았으면 캘리브레이션부터 다시. 장비 준비가 끝나면 계획으로 가고, 그동안 적도의는 홈에서 추적을 끄고 기다린다.
- **실패해도 밤이 막히지 않게**: 극축 정렬·센터링·시험 사진은 건너뛰기, 캘리브레이션·가이드는 "가이드 없이 진행"(그날 밤 가이드 없음, 노출이 60초를 넘으면 줄일지 묻고 자동으로 바꾸지 않음), 이동은 "지금 위치를 목표로"(센터링도 건너뛰되 확정 질문은 남김), 초점은 "지금 초점으로 진행". 건너뛴 작업은 "건너뜀"으로 남는다. **[임시]** 극축 정렬·캘리브레이션·초점의 "[임시] 건너뛰기"(실내 시험용)
- **다시 하기**: 영향받는 뒤 작업만 "다시 확인 필요"가 되어 차례로 다시 지나간다 — 극축 정렬 → 그 뒤 전부 / 캘리브레이션 → 이동·센터링·가이드·시험 사진(초점 유지) / 이동 → 센터링 이후 / 초점 → 초점 확인·시험 사진 / 센터링 → 가이드·시험 사진 / 가이드 → 시험 사진. 진행 중인 동작은 먼저 멈추고 확인.
- 촬영 중 대상을 바꾸면 **대상** 단계로(장비 준비는 유지, 돌던 가이드는 먼저 멈춤).
- **이어서 하기**: 아이라를 다시 켜면(2시간 안) 프로필을 고른 직후 오늘 밤 진행을 이어서 할지 묻는다. 이어서 하면 출발 전 점검을 건너뛰고, 장비 연결 뒤에 먼저 노출·포커서·적도의를 멈추고 확인하고, 끝낸 작업은 장비가 그대로인지 확인한 뒤 건너뛴다. 장비 연결 뒤 확인에 실패하면 이유와 함께 "다시 시도" · "새로 시작하기"(장비 준비부터).
- 시험 사진 두 가지를 섞지 않는다: **탐색 사진**(센터링 솔빙 사진을 그대로 — 구도 판단) / **검증 사진**(확정 뒤 계획 노출 + 가이드 — 초점·별 모양·배경).

### ① 극축 정렬 (세부: 넘겨받기 → 극 찾기 → 정렬 → 돌려주기)
- 사용자가 할 일은 **나사 조절과 버튼**뿐. 가이드 카메라를 PHD2에서 SharpCap으로 넘기고, SharpCap을 켜고(카메라는 지난번 SharpCap이 연 것을 기억), 적도의를 돌리고, 끝나면 SharpCap을 닫고 PHD2에 돌려주는 것은 아이라가 한다(안내 "손대실 것은 없습니다").
- **SharpCap이 이미 켜져 있으면** 넘겨받기 전에 "SharpCap 닫고 다시 켜기"(주) · "극축 정렬 건너뛰기"를 묻는다(켜져 있는 SharpCap은 조종할 수 없음). 사용자가 켠 SharpCap을 강제로 끄지 않는다(창 닫기만, 20초 안에 안 닫히면 안내 + 다시 시도). 아이라가 정리하며 닫는 것은 아이라가 켠 SharpCap뿐.
- **극 찾기**: 추적을 항성으로 켜고, 첫 사진에서 위치를 찾으면 적도의를 RA축으로 약 60° 돌린다(UMi17X는 홈에서 한쪽으로 약 60°까지만 돈다 — 홈 근처에서 출발). 돌리기 직전 케이블 안내. 별이 모자라면 노출을 늘린다. 회전 끝의 멈춤이 들어가지 않았거나 멈춘 것을 확인하지 못하면 비상 정지(드라이버 직접)와 N.I.N.A. 정지를 함께 보내고, 그래도 확인하지 못하면 "다시 시도" 대신 "장비 상태 다시 확인"만. 돌렸거나 돌렸을 수 있으면(도중 취소 포함) **다시 극 찾기를 하기 전에 먼저 적도의를 홈(시작 위치)으로 되돌리고** 다시 돌린다(같은 방향으로 60°를 또 돌리지 않게) — "다시 시도"뿐 아니라 준비를 중단하고 다시 시작하거나 극축 정렬을 다시 할 때도(그날 밤 동안 기억, 홈 도착을 확인해야 지움). 아이라를 다시 켜 이어서 하면 돌렸는지 알 수 없으므로 늘 먼저 홈으로. 되돌리지 못하면 멈춤을 확인한 뒤 "손으로 홈에 옮겼어요"(손으로 홈 근처에 두고 누름 — 자동 홈을 다시 요구하지 않음) / "다시 홈으로 보내기" / 건너뛰기.
- **정렬**: 아이라가 오차를 직접 평가해 "이 계획엔 충분해요 / 조금 더" + 나사별 방향(기준은 오늘 계획의 초점거리·한 장 노출, 계획 전이면 장비 기준). 사용자는 원하는 만큼 맞추고 "정렬 완료". 실제 장비에서는 등급 말 없이 방향·픽셀 값만 보여 준다.
- 노출은 아이라가 정한다(SharpCap 권장 높은 게인·1~2초에서 시작).
- **실패**: 넘겨받기·돌려주기는 몇 번 다시 시도 → 할 일 한 줄 + "다시 시도" / "극축 정렬 건너뛰기". 위치를 못 찾으면 원인별 안내(북극에서 멀리 향함 → 삼각대·고도 나사로 북극 쪽, 구름·창틀·건물, 가이드 망원경 초점).
- 결과는 "사용자 확인"으로만. 앱을 다시 켜도 생략하지 않는다("이미 정렬했어요" 없음).

### ② 캘리브레이션 (세부: 위치로 이동 → 별 선택 → 캘리브레이션)
- 극축 정렬 직후 망원경은 극 쪽이라 맞지 않다 → **적위 0° · 자오선 근처로 옮겨서**(이동 직전 케이블 안내). 결과 = 직교 오차.
- **장비 준비를 시작할 때는 항상 새로**(조립·극축 정렬로 가이드 카메라를 만졌으므로), 같은 밤 대상만 바꿀 때는 재사용("이번 밤 캘리브레이션을 그대로 씁니다" + 새로 하기). PHD2를 다시 켜 보정값이 없으면 새로.
- **위치**: A = 자오선 서쪽 1시간·적위 0°(피어 동쪽, 캘리브레이션 중 자오선에 다가가지 않음) → 안 되면 B = 동쪽 1시간. goto가 "끝"이라 해도 목표에서 2° 넘게 벗어나면 실패.
- 시작 버튼 옆 "가이드 없이 진행"(움직이기 전에 고름).
- **실패·예외**(안에서 재시도, 끝내 안 될 때만 할 일 한 줄): 별 없음(구름·건물·덮개·초점) → 노출 늘려 다시 → A→B → 안내 / 별 자동 선택 안 됨 → "PHD2 화면에서 별을 클릭해 주세요" / 별 포화·가장자리 → 다른 별로 / 도중에 별을 잃음 → 1번 자동 재시작 → 안내 / 별이 안 움직임 → PHD2–적도의 재연결 후 재시도 → 안내 / 끝났지만 PHD2 경고(직교 오차·두 축 속도 차·Dec 백래시) → "다시 하는 게 좋아요" + 이유, "다시 하기"·"그래도 진행" / 약 8분 넘게 → 멈추고 안내 / 장비 끊김 → 재연결 → 무엇이 끊겼는지 / 자오선까지 15분 안 → 다른 위치.

### ③ 초점
- 자동초점 한 번. 포커서가 없으면 "손으로 맞췄어요". 점검을 마쳤으면 먼저 포커서 0점을 잡는다.
- **시작 위치**: 같은 밤에 맞춘 위치 → 망원경별로 저장한 지난 위치(그때 기온과 함께) → **처음이면 넓게 찾기**(자동초점은 시작점 앞뒤 수백 걸음만 봄): 전체 범위를 약 2,000걸음 간격으로 2초씩 찍어 별이 가장 많은 곳, 그 앞뒤를 400걸음 간격으로 찍어 별이 가장 작은 곳 → 거기서 자동초점. 자동초점 범위가 포커서 끝을 넘지 않게 시작점을 끝에서 떼어 둔다.
- 넓게 찾아도 별을 못 찾으면 손으로 대략 맞춘 뒤 **"지금 위치에서 자동초점"**(다시 넓게 찾지 않음) 또는 "초점을 맞췄어요". 손으로 맞춘 위치는 저장하지 않고 자동초점이 성공해야 저장.
- 자동초점이 실패하면 "다시 시도" / "지금 초점으로 진행". 포커서 에러(멈춤 감지)면 바로 멈추고 "포커서가 끝에 닿아 멈췄습니다" + 해제 방법(N.I.N.A. 포커서 설정 창의 "Clear stall" — API 없음).
- 칸 크기·백래시·자동초점 노출은 **N.I.N.A. 설정 그대로**(Oasis: 약 125걸음 = 0.1mm, 백래시 Overshoot 600). 결과는 아이라 말로("좋아요 — 별 크기 2.1, 곡선이 깔끔해요").
- Oasis: 0은 드로튜브를 끝까지 넣은 곳, 최대 56000. 온도 프로브는 포커서를 연결할 때만 잡힌다(나중에 꽂으면 포커서를 다시 연결). "Link board Temp. to ambient Temp."는 꺼 둔다(보드 온도가 기온으로 쓰이면 재초점이 잦아짐).
- 필터별 초점 차이는 모노 카메라를 쓸 때.

### 계획 (대상 단계의 첫 작업)
- **계획 = 무엇을(대상) + 얼마나(촬영 설정)**. 구도(가운데 · 지금 카메라 방향)와 끝난 뒤(파킹 · 다크·플랫 · 연결 해제)는 묻지 않고 기본값으로 넘긴다. 다크·플랫은 늘 찍는다.
- **화면과 AI가 같은 계획을 고친다**: 사용자는 화면에서 직접, AI는 말로 부탁받으면 도구로(대상 고르기·빼기·설정 바꾸기·시작 옮기기). AI는 화면에 보이는 값을 기준으로 말한다. AI가 없으면(키 없음·꺼 둠·한도) 대화 없이 **이름 검색**만 — 대화 도중 한도가 다 되면 그 자리에서 이름 검색으로 바뀐다(답하지 못한 말은 입력창으로 돌아온다).
- **이름 검색**: N.I.N.A. 대상 목록(번호는 앞부분만 맞아도, 한국어 통칭·영문 통칭). 오늘 밤 이 관측지에서 어두운 시간에 15° 위로 한 번도 못 올라오는 대상(그 위도에서 뜨지 않음, 해 근처)은 빼고 보여 준다.
- **고른 대상은 최대 3개**를 그래프에 함께 그린다. 다시 고르면 가장 최근으로, 4번째를 고르면 가장 오래 안 본 대상이 빠진다. "목록에서 제거"로 뺄 수 있고 다 빼면 처음 상태.
- **촬영 시간대** (기준값은 코드 `PlanRules` 한곳):
  - 촬영 시작 = 이동 + **준비 시간**(이동·센터링·초점 확인·가이드·시험 사진). 준비 시간 = 프로필마다 최근 5번 기록의 **중앙값**(분 단위 올림), 기록이 없으면 20분. 기록 = 대상으로 이동을 처음 시작한 때 → 시험 사진을 마친 때(이동 시각을 기다린 시간은 빠짐). 실제 장비로 이동부터 시험 사진까지 모두 실제로 끝낸 때만 남기고, "지금 위치를 목표로"·건너뛰기·이어서 하기로 넘긴 작업이 있으면 남기지 않는다(`Prepare/PrepTimes.cs`). 확정한 계획은 그때의 준비 시간을 갖고 가서 이동 단계가 같은 값으로 옮긴다.
  - 가장 이른 시작 = 지금 + 준비 시간, 어두워지는 때(천문 박명), "이동 때 15° 이상"(15° 도달 + 준비 시간) 중 가장 늦은 때.
  - **기본 시작** = 그 뒤 대상이 **30°** 위가 되는 때(낮게만 지나가는 대상은 가장 이른 시작). **사용자가 시작을 옮길 수 있다**(15° 이상 ~ 끝나기 10분 전, 위쪽 한도 없음). 
  - 끝 = 대상이 **시작 고도와 30° 중 낮은 쪽** 아래로 내려갈 때 또는 새벽(천문 박명). 늦게 시작해도 끝은 30°. 지는 쪽에서 30°보다 낮게 시작하면 15°까지(그 고도가 곧 끝이라 시간이 없어지므로). 시작을 옮겨 시간이 없어지면 "시작을 기본으로" 되돌리기가 보인다.
  - 기다려야 하면 까닭을 나눠 알린다: 어두워지기 · 대상이 30° 위로 · 사용자가 정한 시작.
- **장수**: 총 노출(분) = 한 장 노출 × 장수(쉬는 시간 제외). 끝 시각 = 시작 + 장수 × (노출 + 쉬는 시간 약 40초) + 찍는 동안 자오선을 지나면 5분. 시간대 안에 다 못 찍으면 **찍을 수 있는 최대 장수가 계획 장수**(물리 한계까지).
- **기본값**: 노출·ISO는 대상이 아니라 장비·필터·가이드·달로 정한다(단순 표: 밝은 광학계 짧게, 내로우밴드 2배·ISO 1600, 광해 필터 1.3배(어림값), 가이드 없으면 120초까지, 밝은 달 0.67배). 총 노출 기본 180분, 필터 기본 광해 필터. 필터를 바꾸면 고치지 않은 노출·ISO는 그 필터의 기본값으로 따라간다. ISO는 카메라가 쓸 수 있는 단계 목록에서만(전용 천체 카메라는 범위 안 정수). 기록이 쌓이면 "필터 + 지난번 잘 찍힌 값"으로 **[계획]**.
- 필터는 지금 세 가지 고정(필터 없음 · 광해 필터 · 듀얼 내로우밴드) — 노출 기본값과 기록에만 쓰인다(N.I.N.A.에 필터를 바꾸게 하지 않음).
- **이동 버튼 "○○로 이동"** = 계획 확정(좌표·노출·장수·끝 고도·끝난 뒤 동작은 바뀌지 않는 실행 값) + 이동 승인. 바로 움직일 수 있으면 적도의가 바로 움직이고, 아니면 이동 단계의 "기다리기"로 간다(버튼 이름 "○○ 기다리기 (시각)"). 찍을 수 없는 계획(시간 없음, 끝 시각 지남)이면 넘어가지 않고 이유. 확정 뒤 값을 바꾸려면 "다른 대상"으로 계획에 돌아온다. 센터링·시험 사진·촬영에서 "다른 대상"으로 돌아오면 적도의는 **움직이지 않고 추적만 끈다**(이동까지 오래 기다릴 수 있어 한계 쪽으로 흘러가지 않게 — 장비 준비 뒤 쉬게 하기와 같은 이유). 못 끄거나 적도의 상태를 읽지 못하면 오류 줄에(미연결이라고 분명히 답할 때만 할 일 없음).
- 같은 밤 장비가 바뀌면 대화는 두고 화각을 다시 계산하고, 기본값 그대로이던 노출·ISO만 새 장비의 기본값으로(고친 값은 둔다) + 안내 한 줄. 다른 프로필로 바꾸면 대화를 새로.

### ④ 이동
- 계획의 이동 버튼 = 이동 승인(방금 누른 그 한 번만). **옮기는 때 = 계획의 촬영 시작 − 준비 시간**, 그리고 대상이 **15° 이상**. 늦게 떠오르는 대상은 15°가 되는 때가 이동 시각.
- **누르지 않으면 움직이지 않는다**: 장비 준비를 다시 하고 돌아올 때, 아이라를 다시 켜 이어 갈 때, N.I.N.A.를 다시 켠 뒤, 기다리다 때가 됐을 때는 케이블 안내와 함께 "○○로 이동"을 다시 묻는다. 누르는 사이, 또는 적도의가 다른 동작(홈 등)을 마치기를 기다리는 사이 15° 아래로 내려갔으면 이동 명령을 보내지 않고 다시 기다리기(적도의를 잡은 뒤 명령 바로 앞에서 다시 본다).
- 그 전이면 **바로 기다리는 화면**(따로 "기다리기"를 누르지 않음) — 남은 시간을 보여 주고 때가 되면 알림 → "○○로 이동". 15° 아래면 버튼 없이 기다리기만(이동은 막음, "약 n분 뒤 15° 위로 올라오면 알려 드립니다"), 시각만 이르면 버튼은 **"지금 이동"** 하나로 먼저 옮길 수 있다.
- 도착 확인(목표에서 2° 안). 이동 중 **멈춤** 버튼과 "케이블이 걸리면 멈춤을 누르세요". 다른 동작(홈 이동 등)이 적도의를 쓰는 중이면 그것이 끝난 뒤 멈춤 버튼과 함께 출발.
- 자오선 반전은 막지 않는다(촬영 중 아이라가 자동으로).
- 실패: 응답 없음·시간 초과는 멈춤이 아니다 → **멈추고 멈춘 것을 확인한 뒤에만** "다시 시도" / "지금 위치를 목표로"(확인 못 하면 "장비 상태 다시 확인"만). 캘리브레이션 위치 이동·센터링의 맞춤 이동도 같다(캘리브레이션은 멈춘 뒤 "다음 위치로 이동"을 누를 때 다음 위치로).

### ⑤ 센터링 (탐색)
- 사진 · 솔빙 · 보정 반복, 카메라 방향은 돌리지 않음. N.I.N.A. 플레이트 솔빙 설정 그대로(이 PC: ASTAP + D50, 노출 2초, 허용 오차 1′, 최대 10번). 솔빙으로 맞춘 동기화는 정상(홈에서의 수동 싱크와 다르다).
- 결과 "가운데에 맞췄어요 — 오차 0.4′" + 카메라 방향 기록(다음에 같은 대상이면 "지난번 87°"). 그 사진이 **탐색 사진** → **"이 대상으로 확정" / "다른 대상"**(다른 대상이면 계획 대화로).
- 실패: 솔빙 실패 → 노출 늘려 다시 → 전체 하늘 검색 → "초점이나 구름을 확인해 주세요" + "초점 다시 맞추기"·"다시 시도". 10번 넘게 안 맞으면 멈추고 안내.
- **구도 회전**: 센터링을 마친 사진 위에서 사용자가 틀(찍히는 범위)을 돌려 원하는 구도를 정하면, 사진 가운데에 "카메라를 ○ 방향으로 N° 돌려 주세요(카메라 뒤에서 볼 때)". 사용자가 망원경의 로테이터 링으로 카메라를 돌리고 "돌렸어요 · 다시 찍기"를 누르면 센터링을 다시 하고, 새 사진의 카메라 방향(솔빙)으로 남은 각도를 잰다 — **2° 안**이면 맞춘 것(틀을 지움), 아니면 남은 만큼 다시 안내(오히려 멀어졌으면 반대쪽으로). 언제든 "이 대상으로 확정"으로 지금 구도대로 넘어갈 수 있다. 카메라 방향을 읽지 못한 사진에서는 틀을 돌릴 수 없다(돌린 뒤 확인할 수 없으므로). 정해 둔 구도는 그 계획에만 쓴다 — 다른 대상을 골랐다가 같은 대상으로 돌아와도 새로 확정한 계획이라 쓰지 않는다(`Prepare/Tasks/Center/Framing.cs`). 회전 방향의 부호는 **[실기 확인]**(`Framing.AnglePerTurn`, web `framing.ts`의 `CAMERA_TURN_SIGN`).
- **[계획]** 링 눈금과 솔빙 각도를 한 번 짝지어 "링을 N으로 돌리세요"(실기 뒤).

### 초점 확인 (확정 뒤)
- 맞출 때와 기온 차 2°C 이상, 또는 센터링 사진 별 크기가 초점 때보다 30% 이상 큼(별이 충분할 때만) — 하나라도 걸리면 "다시 맞출까요?", 아니면 근거를 잠깐 보여 주고 가이드로.

### ⑥ 가이드 (세부: 별 선택 → 안정화 → 측정)
- N.I.N.A.를 통해 시작(디더링·반전 후 재시작이 상태를 알도록), 측정은 PHD2에서. 가이드 노출은 아이라가 별 신호로(시작값 1~2초 — 하모닉 적도의의 짧은 주기 출렁임).
- 판정 = 오차를 **주 카메라 한 픽셀**(N.I.N.A. 프로필로 계산, 사용자 장비 2.41″)과 비교: 이하 "충분해요" / 1.5배 이하 "괜찮아요, 지켜볼게요" / 그 이상 "아쉬워요" + 짐작 원인. 측정값 없으면 통과 금지. **확정은 사용자 "좋아요"**. 가이드를 쓰지 않으면 건너뜀.
- 실패: 별을 잃음 → 다시 고르기, 오차가 계속 커짐 → 원인 안내, 캘리브레이션이 안 맞음 → 캘리브레이션 다시 하기 제안.

### ⑦ 시험 사진 (검증 사진)
- **항상** 계획한 노출로 한 장(긴 노출의 추적·가이드, 배경 밝기·ISO, 이슬 확인). 확인용으로만 — 촬영 첫 장으로 쓰지 않는다. "촬영 시작" / 다시 찍기 / 다시 센터링.
- 규칙으로 바로 검사: 별 크기가 초점 결과보다 커졌나("초점이 밀렸어요, 다시 맞출까요?"), 별이 한쪽으로 길쭉한가(가운데 칸 별의 이심률이 0.6을 넘고 길쭉한 방향이 한쪽으로 모였으면 — **[임시]** 0.5 — "가이드나 추적이 흔들렸을 수 있어요" + 가이드 다시 재기. 방향이 제각각이면 광학·잡음 탓이라 묻지 않는다), 배경 밝기("노출을 줄이는 게 좋아요"), 포화 비율, 가이드 오차 → "좋아요, 촬영을 시작해도 돼요" 또는 문제 + 할 일. 노출을 바꿔야 하면 "120초 → 90초로 바꿀까요?" → 동의하면 계획에 반영하고 다시 찍기.
- 실패: 내려받기 실패 → 한 번 다시 → 카메라 연결 확인 안내.
- **별 모양**: 별은 솔빙에 쓰는 ASTAP의 `astap_cli -extract`로 찾고(X-T5 원본 FITS를 그대로 읽어 별마다 위치·크기(HFD)·SNR — 80MB 한 장 약 1초), 길쭉함(이심률)·방향은 아이라가 사진 화소로 잰다. ASTAP이 없거나 별을 못 찾으면, 또는 사진 옆에 같은 이름의 CSV가 이미 있으면(사용자 파일일 수 있어 건드리지 않음) 별 모양 검사는 빠진다. Advanced API는 Hocus Focus의 수차 검사 결과를 넘겨주지 않는다(넘겨주는 플러그인은 TPPA·Livestack·Target Scheduler뿐).
- **아홉 칸**: 귀퉁이 넷과 가운데의 별 크기를 견준다 — 가장 큰 귀퉁이가 가장 작은 귀퉁이의 **[임시]** 1.2배를 넘으면 기울어짐 의심(이웃 귀퉁이도 크면 그 변), 귀퉁이 평균이 가운데의 **[임시]** 1.25배를 넘으면 백포커스·상 굽음, 아니면 고름. 칸마다 별이 **[임시]** 5개가 안 되면 판정하지 않는다. 지금은 검사 글과 끝 안내로 알려만 주고 촬영을 막지 않는다(조절 순서는 아래 **[계획]** 4).
- **밝기 눈금**: 사진 밝기(배경·포화·플랫 50%)는 카메라의 실제 눈금으로 읽는다 — 눈금(전체 범위)은 알려진 비트 수가 바닥이다 — 후지 원본은 14비트(사진의 카메라 이름), 아니면 N.I.N.A.의 "비트 수". 사진 값이 그보다 크면 그 값을 담는 12·14·16비트로 올리고, 사진이 어둡다고 내리지 않는다(알려진 것이 없으면 사진 값을 담는 눈금). 포화되는 값은 그 눈금이되, 가장 밝은 값에 점이 몰려 있고 그 값이 눈금의 90% 위면 그 값. 빛이 없을 때의 바닥값(후지 14비트 원본 1024, 모르는 카메라 **[임시]** 0)과 함께 시험 사진에서 정해 그날 밤 플랫에도 쓴다. 시험 사진이 없으면 N.I.N.A. 비트 수로.
- **[계획]** 노출 맞추기와 틸트 (2026-10-15 합의, 구현 전):
  1. 계획한 노출로 한 장.
  2. 배경 밝기로 필요한 노출을 계산해 바꾸고 확인용으로 한 장 더(보통 2장, 많아야 3장). 적도의가 움직이지 않으니 묻지 않고 바꾸고 바뀐 값만 보인다. 바꾼 노출은 계획에 반영(장수 다시). 늘릴 때 상한: 가이드 없으면 120초, 있으면 **[임시]** 300초. 포화 비율이 기준을 넘으면 줄인다.
  3. 적정 노출 = 하늘 배경(바닥값을 뺀 전자 수)이 읽기 잡음 제곱의 약 10배가 되는 가장 짧은 노출(읽기 잡음이 더하는 잡음이 5% 안팎 — 더 길게 찍어도 얻는 것은 적고 포화·별 흐름 위험만 큼). 카메라의 ISO별 읽기 잡음·게인은 공개 측정값이나 마무리 다크로. 모르는 카메라는 바닥 위 **[임시]** 5~10%(카메라 화면 히스토그램의 1/4~1/3쯤).
  4. 정한 노출의 사진으로 아홉 칸 판정(위 "아홉 칸"). 조절이 필요한지는 아이라가 판단해 보여 주고, 조절할지는 사용자가 정한다. 조절하면 가이드를 멈춤 → 사용자가 조절 → 초점 확인 → 센터링 확인 → 틸트 확인 사진 한 장(조절 전과 나란히). 극축 정렬·캘리브레이션은 다시 하지 않는다(가이드 카메라가 OAG면 캘리브레이션 확인 **[확인 필요]**). 지난번과 같은 결과에 "그대로"를 골랐으면 다음부터 한 줄로만. 판정 기준은 실제 딥스카이 사진으로 다듬는다.
  5. 본 촬영 시작 — 초점 밀림·가이드·포화 검사도 마지막 사진으로.
- 시험 사진은 N.I.N.A.가 SNAPSHOT으로 저장하고(촬영 사진과 섞이지 않게), 받은 뒤 같은 날짜 폴더의 **"시험" 폴더**로 옮긴다. 못 옮기면 SNAPSHOT 폴더에 그대로 둔다.

## 6. 촬영

- 아이라가 한 장씩 시킨다(연속 촬영을 N.I.N.A. 시퀀스에 맡기지 않음).
- **등급 A+ · A · B · C · F**: 그날 밤 초점 때 별 크기·가이드·처음 좋은 사진들의 별 수·배경을 기준으로 규칙이 매긴다.
- **F = 제외 폴더로 옮김**(지우지 않고, 지울지 묻지도 않음 — 사용자가 밖에서 정리). 별 흐름(가이드·모양) · 구름(별 수 급감) · 잡광(배경 급증) · 초점 크게 나감. 계획 장수는 **쓸 사진** 기준(제외한 만큼 더 찍음). 상태 줄 "48번 사진: 별이 흘렀어요 · 제외 폴더로 옮겼어요".
- **묻지 않고 자동**: 디더링(쓸 사진 3장마다), 자오선 반전(항상 — 반전 → 다시 센터링 → 가이드 재시작, 끄는 선택 없음), 초점 다시 맞추기(기온 2°C 또는 최근 별 크기 30%), 구름(가이드 별을 잃으면 멈추고 돌아오면 이어서 — 지금 노출은 끝까지 찍고 그 장을 버림).
- **끝**: 계획 장수 · 대상이 **내려가며** 계획의 끝 고도(기본 30°, 시작을 낮게 잡았으면 그 고도) 아래 · 계획 끝 시각이면 저절로 → 가이드 정지 확인 → **추적 끄기**(사람이 없을 수 있다 — 켜 두면 아침까지 RA축이 돈다. 못 끄면 경고) → "촬영을 마쳤어요" + "플랫 찍으러 가기"(주) / "다른 대상으로 변경"("계속 찍기" 없음). 올라오는 중에 일찍 시작했으면 고도로 끝내지 않는다.
- 촬영 중에는 PC가 절전에 들지 않게 한다(화면은 꺼져도 됨).
- 반전·초점 다시 맞추기 사이에 끝 조건이 되거나 멈춤을 눌렀으면 새 사진을 시작하지 않는다.
- **촬영 중단**(레일 아래, 촬영 중에만) → "끝내고 마무리하기"(주) / "다른 대상으로 변경" / "계속 찍기". 지금 사진은 끝까지 찍고 가이드를 멈춘 뒤. 다른 대상 = 대상 단계(계획)로 돌아가기.
- 가이드가 15분 넘게 안정되지 않으면 "그대로 찍기 / 더 기다리기"를 묻는다. 가이드 정지·적도의 정지를 확인하지 못하면 다음으로 가지 않고 "장비 상태 다시 확인".
- 촬영에 들어가면 적색 테마로 자동 전환, 대상 단계(계획)로 돌아가면 원래 테마로(마무리·요약은 그대로). 사용자가 직접 바꾸면 그 선택을 따른다.

## 7. 마무리

- 작업: **플랫 · 다크 · 장비 정리**. 사용자가 할 일(패널 씌우기, 뚜껑 덮기)만 묻고 나머지는 이어서.
- **플랫**: 망원경을 위(자오선·고도 약 80°)로 → "플랫 패널을 씌우고 켜 주세요" → 노출은 평균 밝기가 바닥~포화의 50% 근처가 되게 찾음(밝기 눈금은 ⑦, ISO는 촬영과 같게) → **30장**. 노출이 1/250초보다 짧으면(셔터 그림자) "패널이 너무 밝아요" — 밝기를 줄이거나 천을 한 겹 더.
- **다크**: "패널을 끄고 렌즈 뚜껑을 덮어 주세요" + 다크 장수(5장씩 5~40, 기본 20, 예상 시간). 덮으면 적도의는 홈으로(동시에), **플랫 다크 30장 → 다크**(그날 찍은 노출·ISO마다). 찍는 중 "여기까지만 찍기 (n장)". 바이어스는 찍지 않음(플랫 다크·다크가 대신). 온도별 다크 라이브러리는 냉각 카메라를 쓸 때.
- **장비 정리**(묻지 않음): 적도의 홈 · 추적 끔 → 포커서 0 → 장비 연결 끊기 → N.I.N.A.·PHD2 닫기 → **오늘 밤 요약**(대상별 쓸 사진·누적·제외 폴더, 보정 프레임, 폴더·등급 분포).

## 8. 적도의 홈 버튼

- 누르면 확인 뒤 홈으로 보내고 추적을 끈다.
- 움직이면 안 되는 때는 잠긴다: 촬영 중, 적도의를 쓰는 작업(극축 정렬·초점 등 준비 작업) 진행 중, 가이드 중, 실제로 움직이는 중(N.I.N.A.에서 직접 시작한 이동 포함), 적도의 미연결. 준비 작업 중이면 "준비 중단" 뒤에 풀린다.
- 홈 도착을 확인하지 못하면 멈추고 멈춘 것을 확인한 뒤 안내. 멈춘 것도 확인하지 못하면 "적도의 확인 필요"로 남아, 사용자가 "멈춘 것을 확인했어요"를 누를 때까지 **적도의를 움직이는 모든 작업**을 막는다(그 작업은 이유와 "다시 시도"). 장비 준비 끝의 자동 홈도 같은 절차.

## 9. 앱 전체

### 아이라 종료
- 레일의 종료 버튼과 창 ×가 같은 절차. 프로필 화면에서도 창 ×는 이 절차(미리 켠 프로그램을 닫아야 해서). 마지막 요약에서는 바로 닫는다.
- 확인: "(지금 단계) 진행을 중단하고 아이라를 종료합니다." 그 아래 **지금 떠 있는 N.I.N.A.·PHD2·SharpCap·Empire를 누가 켰든 모두 체크 목록으로**(처음엔 모두 체크 — 남길 것만 끈다). 종료 · 취소(처음 초점은 취소). 촬영 중이면 "촬영을 중단하고 아이라를 종료합니다. 지금 촬영 중인 사진 노출이 끝나면…" — 지금 사진이 끝나면 멈추고 평소 종료 순서(추적 끄기·포커서 0·장비 연결 끊기·프로그램 닫기)를 그대로 한다.
- 순서: ① 진행 중인 준비 작업(이동·자동초점·가이드)과 홈 이동을 멈추고 확인 — **촬영 중이면 지금 사진이 끝나 받을 때까지 기다려 촬영을 끝낸다**(아이라가 꺼지면 다음 사진·반전·끝 조건을 볼 주체가 없다) ② **적도의 추적 끄기**(상태를 읽지 못하면 끈 것으로 치지 않음 — 켜진 채 남으면 몇 시간 뒤 RA축이 크게 돌아가 있다) ③ 포커서를 0으로 ④ 장비 연결 중이면 멈추고 끊기(보낸 연결 요청의 답을 최대 1분 기다린 뒤) ⑤ **체크한 프로그램을 차례로 닫기**(N.I.N.A. → PHD2 → SharpCap → Empire, 체크를 끈 것은 "남겨 둠").
- **N.I.N.A.를 남기고 다른 것을 닫으면 N.I.N.A.의 장비 연결을 먼저 모두 끊는다**(가이더 → 카메라 → … → 적도의). 연결된 채 PHD2·Empire가 사라지면 N.I.N.A.가 연결을 잃었다는 오류 창을 띄운다. N.I.N.A.를 닫으려다 못 닫았으면(저장 확인 창 등) 뒤의 것은 닫지 않는다.
- 촬영 중이면(촬영 정지를 확인하기 전) 닫지 않는다. 모의 장비로 돌 때는 목록이 비고 아무것도 닫지 않는다(시연 중 켜 둔 실제 프로그램을 건드리지 않게).
- 어느 단계든 확인하지 못하면(작업 정지·연결 끊기 확인 못 함, 목록을 못 받음, 응답 없음) 거기서 멈추고 안내 + "그래도 종료"(이때 프로그램은 남김). 프로그램 하나가 안 닫히면(저장 확인 창 등) 뒤의 것은 "남겨 둠" + 안내 + "그래도 종료".
- **"그래도 종료"도 끄기 전에 가이드 멈춤과 추적 끄기를 한 번씩 시도**한다(촬영 중이어도). 추적을 끄지 못했으면 "추적이 켜져 있을 수 있어요 — N.I.N.A.에서 꺼 주세요"를 보이고 한 번 더 누르면 끈다. 화면이 응답하지 않아 창이 직접 닫을 때도 같은 시도를 한다.
- 촬영이 적도의 정지를 확인하지 못한 채 끝났으면(반전 실패 등) 그 확인 전에는 종료 절차가 프로그램을 닫지 않는다.
- **Windows가 꺼지거나 다시 시작·로그오프할 때**(업데이트 자동 재시작 포함): 종료 절차를 밟을 시간이 없어 가이드 멈춤·추적 끄기만 한 번 시도한다(최대 10초, 그동안 Windows 종료 화면에 이유). Windows 종료를 막지는 않는다.
- 종료를 취소하고 돌아오면 멈춘 작업에 "다시 시작".
- **화면이 고장 나도 종료는 남긴다**: 화면 하나가 실패하면 그 자리만 다시 그리기, 앱 화면 전체가 실패해도 종료 버튼은 남는다. 화면(WebView2) 프로세스가 죽거나 멈추면 창이 다시 불러오고(1분에 세 번째·브라우저 전체가 죽으면 다시 켜 달라는 안내), 창 ×를 화면에 물었는데 3초 안에 답이 없으면 창이 직접 "그래도 닫을까요?"(종료 절차를 못 거친다는 것과 추적을 직접 끄라는 안내와 함께). 오류는 기록 파일에.

### 다른 프로그램 창이 아이라 위로 뜨지 않게
- 아이라가 켜거나 켜지게 하는 N.I.N.A.·PHD2·Wanderer Empire·SharpCap은 **켜지는 동안 아이라를 잠깐 "항상 위"로** 두어 새 창이 아이라 뒤에서 열리게 하고, 새 창이 포커스를 가져가면 아이라로 되돌린다(최소화하지 않음 — 한 번 보였다 사라져 문제처럼 보이고, SharpCap은 최소화하면 영상을 비출 수 없음). Wanderer Empire 시작 로고("항상 위" 창)는 그 표시를 푼다.
- 미리 열려 있던 창, 지켜보기가 끝난 뒤 사용자가 연 창, 목록에 없는 창(ASCOM 드라이버 설정 창 등)은 건드리지 않는다. 사용자가 Alt+Tab·Windows 키로 직접 창을 바꾸면 지키기를 그만둔다(2분 동안 다시 앞을 차지하지 않음).

### N.I.N.A. 오류 알림
- N.I.N.A.의 알림(오른쪽 아래 토스트)은 영어·번역 누락이 섞이고 아이라 종료 버튼 자리와 겹친다 → 아이라가 N.I.N.A. 로그를 읽어 **진단 카드**로 풀어 쓴다(무슨 일 / 왜 / 이렇게, 원본은 접어서). 같은 알림이 1분 안에 또 오면 횟수만.
- 아이라 창이 앞에 있는 동안 N.I.N.A. 알림 창은 숨기고 **돌려주지 않는다**(돌려준 알림을 닫으면 N.I.N.A.가 아이라 위로 올라옴) — 해석 규칙이 없는 알림도 로그 원문으로 "N.I.N.A. 알림"을 만든다. 로그에도 없을 때만 돌려주되 눌러도 앞으로 오지 않는 창으로. 사용자가 N.I.N.A.로 가 있으면 그대로 보인다.
- 지금 화면이 스스로 보여 주는 종류는 띄우지 않는다: 장비 연결 = 연결 실패, 준비·대상·촬영 = 솔빙·가이드, 마무리 = 아이라가 연결을 끊어 생기는 적도의·가이더 오류.

### N.I.N.A.가 꺼지거나 멈췄을 때
- 엔진 켜기에서 연결되면 지켜본다: 프로세스가 끝나는 순간은 운영체제 알림으로 바로, 멈춤은 10초마다 짧게 물어 3번 연속 무응답이면.
- 장비 연결 이후 화면에서 그렇게 되면 상태 줄 장비 점이 모두 꺼지고 진단 카드 "N.I.N.A.가 꺼졌습니다 / 응답하지 않습니다" + **"다시 켜기"** → 엔진 켜기 → 장비 연결 → **원래 화면으로**(점검을 다시 묻지 않음, 계획은 그대로). 촬영 중이었으면 촬영을 멈추고 대상 단계를 이동부터.

### 설정
- 앱 전체에 걸린 값만: **AI 비서**(켜기·끄기, Gemini 키는 이 PC의 Windows 계정으로만 풀리게 암호화해 저장, 화면에 키를 다시 보여 주지 않음), **프로그램 경로**(N.I.N.A.·SharpCap — 자동으로 찾고, 못 찾으면 직접 고름), **기록**(기록 폴더 열기 · 진단 내보내기 = 최근 기록 zip을 바탕 화면에, AI 키 제외).
- 장비·관측지·전원 설정은 프로필에, 테마는 상태 줄에. **안전 동작(포커서 0, 추적 끄기)은 설정으로 끄지 못한다.**

### 새 버전 알림
- 업데이트를 권하지 않고 알리기만(프로필 화면에만, 작업 화면에는 없음). 대상: N.I.N.A. · Advanced API(설치된 N.I.N.A.에서 쓸 수 있는 버전만) · ASCOM Platform · PHD2 정식판. 최신 버전은 하루 한 번만 확인, 인터넷이 없거나 실패하면 아무것도 보이지 않는다. "이 버전은 다시 알리지 않기"(더 새 버전이 나오면 다시). 아이라가 쓸 수 없는 옛 버전은 알림이 아니라 설치 확인에서 막는다.

### AI 비서
- 계획 화면의 대화에서만 쓴다(대상·촬영 설정 고르기). 장비 동작·판정·실패 안내는 규칙과 진단 카드가 맡고 AI는 끼지 않는다.
