# 사용자가 확인할 것

사용자가 직접 해야 확인되는 것. Claude가 확인할 것은 [CLAUDE_TESTS.md](CLAUDE_TESTS.md).
- 새로 생기면 Claude가 알맞은 칸에 `- [ ] (추가한 날) 할 일 — 무엇을 보면 되는지`로 적는다.
- 해 보면 `[x]`로 바꾸고 `→ 날짜 · 결과 한 줄`을 붙인다(문제가 있으면 대화로). 체크한 항목은 다음 정리 때 Claude가 지운다(기록은 HISTORY.md).
- 하는 일은 [OPERATION_PROCEDURE.md](../OPERATION_PROCEDURE.md), 화면은 [DESIGN.md](../../DESIGN.md).

## 먼저 지킬 것 (장비 안전 — 확인 항목이 아니라 늘 지키는 규칙)

- Oasis 포커서 **멈춤 감지(Stall detection) 켜짐** — 넓게 찾기가 포커서 끝까지 간다
- 적도의는 **Go Home만, Set Home은 절대 쓰지 않는다**
- 첫 극 찾기 RA 회전은 **눈으로 지켜보기** — 방향(부호)·60° 한계·케이블
- 촬영 끝: 아이라 종료 → Windows 종료 → 적도의 전원 (PC 전원이 적도의를 거치는 동안)
